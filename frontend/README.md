# Film Zevkini Keşfet — Frontend Demo

Bu klasör mevcut HTML demosunun HTML, CSS ve JavaScript dosyalarına ayrılmış halidir.

## Çalıştırma

`index.html` dosyasını tarayıcıda açın. VS Code Live Server da kullanılabilir.
Kurulum veya npm komutu gerekmez.

## Dosyalar

- `index.html`: Ekranların HTML yapısı.
- `css/style.css`: Görünüm ve mobil stiller.
- `js/data.js`: Temsili film ve kullanıcı verileri.
- `js/app.js`: Ekran geçişleri, oylar, adaylar, temsili giriş ve sohbet.

## Önemli

- Supabase bağlantısı henüz yoktur.
- E-posta doğrulaması gerçek değildir: herhangi bir 6 haneli kod kabul edilir.
- Film afişleri SVG ile temsili üretilir.
- Eşleşme puanları, adaylar ve sohbet yalnızca demo verisidir.
- Sayfa yenilenince oturumdaki bilgiler sıfırlanır.
- İlk 10 şartı yalnızca 1–5 arası puanlanan filmleri sayar; İzlemedim sayılmaz.
- Gerçek kullanıcı bilgileri ve şifreleri bu demo mantığıyla üretimde saklanmamalıdır.
